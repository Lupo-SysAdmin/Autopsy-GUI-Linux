No valida todos los módulos de ingestión. El paquete registra las dependencias de construcción y SHA256SUMS identifica los artefactos finales.

Mensajes conocidos al iniciar: falta `opencv_java2413` para detección de rostros, avisos de módulos JavaFX, proveedores de logging y un fallback de acceso reflectivo GTK. La ventana principal abre, pero no se promete paridad completa. No se utilizaron evidencias reales.
